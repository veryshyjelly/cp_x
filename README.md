# 🏆 Competitive Programming Monorepo

This repository contains competitive programming solutions organized by programming language into separate branches.

Each branch holds the code for a single language. Switch to a branch to view its code:

| Branch | Language |
|--------|----------|
| `ac_rust` | Rust (AtCoder) |
| `arm` | ARM64 Assembly |
| `clj` | ClojureScript |
| `cpp` | C++ |
| `gleam` | Gleam |
| `haskell` | Haskell |
| `lean` | Lean 4 |
| `llvm` | LLVM IR |
| `nim` | Nim |
| `ocaml` | OCaml |
| `python` | Python |
| `rust` | Rust |

This `main` branch contains only this README and the LICENSE. No code lives here — each language's solutions live on its own branch named after the language.
