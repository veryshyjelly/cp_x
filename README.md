# 🏆 Rust (AtCoder) Solutions

This branch contains competitive programming solutions written in Rust, primarily from AtCoder problems.

## Repository Structure
- `src/` - Contains Rust source files including `main.rs` and `cpio.rs` (fast I/O parsing)
- `Cargo.toml` - Rust project configuration
- `Cargo.lock` - Lock file for Rust dependencies
- `eitri.yml` - Configuration for the cocom tool
- `src/bin/` - Contains individual problem solutions (abc240-b.rs, abc242-b.rs, etc.)
- `.gitignore` - Git ignore rules

## How to Use
1. Navigate to a problem directory (e.g., `cd src/bin`)
2. Run `cocom` to automatically build and test your solution
3. Or manually compile with `cargo run --bin <problem_name>`
